# 银行流水检验工具

自动识别多银行流水 Excel 文件（.xlsx 和 .xls），提取关键字段并合并输出总表。当前支持 **北京银行** 和 **东亚银行**。

---

## 1 快速开始

### Windows 用户

双击项目根目录下的 **`run.bat`**，脚本会自动完成以下操作：

1. 检测 Python 环境，未安装则通过 winget 自动安装
2. 安装所需依赖
3. 启动程序

### macOS / Linux 用户

在终端中执行：

```bash
chmod +x run.sh
./run.sh
```

脚本会自动检测并安装 Python（通过 Homebrew / apt / dnf / yum），安装依赖，然后启动程序。

> **提示**：如果系统中没有安装 tkinter（图形界面组件），启动脚本会尝试自动安装。  
> 如果安装失败（例如无 sudo 权限），程序将自动切换为 **命令行交互模式** 运行，不影响核心功能。

### 手动运行

如果已有 Python 环境，也可以手动安装依赖并运行：

```bash
pip install -r backend/requirements.txt
python backend/bankcheck.py
```

---

## 2 打包为 exe

进入 `backend/` 目录，双击 **`build.bat`** 即可一键完成：

1. 自动安装依赖
2. 调用 PyInstaller 打包
3. 生成的可执行文件位于 `backend/dist/bankcheck.exe`

> 打包完成后，将 `backend/dist/bankcheck.exe` 复制到任意位置即可独立使用（无需 Python 环境）。

## 3 操作指南

### 准备工作

将 **主体查找表**（一个 Excel 文件）放在与 `backend/bankcheck.py`（或 `bankcheck.exe`）**同一目录** 下。

- **推荐文件名**：`主体查找表.xlsx`（程序优先按此名称查找）
- 如果文件名不是 `主体查找表.xlsx`，则该目录下只能有 **一个** Excel 文件（排除程序输出的总表），否则程序无法确定查找表
- 查找表格式：**B 列** 为银行账号，**A 列** 为对应的主体名称

### 使用流程

```
1. 运行程序 → 弹出文件夹选择框（无图形界面时自动切换为命令行输入）
2. 选择存放银行流水 Excel 的文件夹
3. 程序自动处理，完成后弹窗/终端提示结果
```

### 程序行为

| 步骤 | 说明 |
|------|------|
| 复制文件夹 | 在原文件夹同级目录创建 `原名＋检验版` 副本，**原文件夹不受影响** |
| 扫描文件 | 递归扫描副本中所有 `.xlsx` / `.xls` 文件 |
| 格式兼容 | `.xls` 文件自动转换为 `.xlsx` 后再处理（需 `xlrd` 库） |
| 识别银行 | 按文件名前缀判断（如 `北京银行xxx.xlsx` → 北京银行） |
| 提取数据 | 按对应银行规则提取指定列，添加 `唯一id` 和 `银行` 列 |
| 清理文件 | 删除已成功处理的 Excel 文件，**保留无法识别和处理出错的文件** |

### 输出文件

- **`银行流水总表.xlsx`** — 生成在程序（`.py` 或 `.exe`）所在目录下
- 包含列：`唯一id`、`银行`、`银行账号`、`主体`、`交易日期`、`付款`、`收款`、`摘要`、`对方户名`、`余额`、`交易流水号`

## 5 题目内容

我想在'C:\Users\wangtiange\TraeProjects\Bank_statement'这个文件夹里面建一个python文件写代码，文件名叫'bankcheck'。我准备设计一个exe程序（你不需要写出exe程序，只需要能实现功能的python代码就行，因为我准备使用Pyinstaller直接打包python文件成exe），需要实现的功能是：用户上传一个文件夹，你需要先在文件夹同路径下复制一份，命名为"原名＋检验版"，然后☞对复制后的文件夹进行操作，原本的文件夹不进行任何操作，随后扫描文件夹中的所有不同银行的流水excel文件（可能里面还包含文件夹，你需要把所有的excel找出来），你需要根据excel文件名最开始的几个字判断是哪个银行（我后面会给你判断依据），根据判断出来的银行选择不同的提取方法（因为每个银行的流水excel文件格式不一样），从不同银行的流水excel表中取出'银行账号'、'主体'、'交易日期'、'付款'、'收款'、'摘要'、'对方户名'、'余额'、'交易流水号'这几列，并在开头根据前面判断出来的银行在这几列前面加上'银行'列，随后需要在最新的这几列前面再新加一列'唯一id'，此列取值为'当前时间戳'＋'uuid'，提取完成后需要把处理完的excel表删除，只留下无法判断银行的文件，所有处理的excel文件最终只需要输出一个总表，包含'银行'、'银行账号'、'主体'、'交易日期'、'付款'、'收款'、'摘要'、'对方户名'、'余额'、'交易流水号'这几列，命名为'银行流水总表'，并放在与代码文件相同路径下。 

现在我想先做出一个能够识别两个银行的程序： 

分类 1：excel 文件以 "北京银行" 开头 

银行：北京银行 

银行账号：对应 excel 文件中的 B2 单元格 

主体获取规则：根据 "银行账号"，到 python 代码存放路径里的唯一 excel 文件中，找到 B 列对应的 "银行账号"，取其同一行的内容 

交易日期：提取该 excel 文件中 B 列第四行至最后一行的内容 

付款：若该 excel 文件中 D 列第四行至最后一行有数字，先取负再填入；无数字则不填 

收款：若该 excel 文件中 E 列第四行至最后一行有数字，直接填入；无数字则不填 

摘要：提取该 excel 文件中 L 列第四行至最后一行的内容 

对方户名：提取该 excel 文件中 G 列第四行至最后一行的内容 

余额：提取该 excel 文件中 F 列第四行至最后一行的内容 

交易流水号：提取该 excel 文件中 P 列第四行至最后一行的内容 

分类 2：excel 文件以 "东亚银行" 开头 

银行：东亚银行 

银行账号：对应 excel 文件中的 B1 单元格 

主体获取规则：同 "北京银行" 分类的主体规则 

交易日期：提取该 excel 文件中 A 列第五行至最后一行的内容 

付款：若该 excel 文件中 D 列第五行至最后一行有数字，先取负再填入；无数字则不填 

收款：若该 excel 文件中 E 列第五行至最后一行有数字，直接填入；无数字则不填 

摘要：提取该 excel 文件中 L 列第五行至最后一行的内容 

对方户名：提取该 excel 文件中 L 列第五行至最后一行的内容 

余额：提取该 excel 文件中 I 列第五行至最后一行的内容 

交易流水号：提取该 excel 文件中 K 列第五行至最后一行的内容


### 支持的银行及提取规则

#### 北京银行（文件名以"北京银行"开头）

| 字段 | 来源 |
|------|------|
| 银行 | 固定值：`北京银行` |
| 银行账号 | B2 单元格 |
| 主体 | 根据银行账号在查找表中匹配 |
| 交易日期 | B 列，第 4 行起 |
| 付款 | D 列第 4 行起，有数字则取负 |
| 收款 | E 列第 4 行起，有数字则直接填入 |
| 摘要 | L 列第 4 行起 |
| 对方户名 | G 列第 4 行起 |
| 余额 | F 列第 4 行起 |
| 交易流水号 | P 列第 4 行起 |

#### 东亚银行（文件名以"东亚银行"开头）

| 字段 | 来源 |
|------|------|
| 银行 | 固定值：`东亚银行` |
| 银行账号 | B1 单元格 |
| 主体 | 根据银行账号在查找表中匹配 |
| 交易日期 | A 列，第 5 行起 |
| 付款 | D 列第 5 行起，有数字则取负 |
| 收款 | E 列第 5 行起，有数字则直接填入 |
| 摘要 | L 列第 5 行起 |
| 对方户名 | L 列第 5 行起 |
| 余额 | I 列第 5 行起 |
| 交易流水号 | K 列第 5 行起 |

### 唯一 ID 生成规则

每条记录的 `唯一id` = **当前时间戳**（`YYYYMMDDHHMMSSffffff`）+ **UUID**（32 位十六进制）。
